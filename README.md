# \# MControl（自作・オフライン版）

# 

# 市販のBLE機器を、公式アプリを使わずに操作する自作アプリです（Android版・iOS版）。

# 機器とは接続せず、BLEの電波（アドバタイズ）で命令を送ります。

# 

# \## 特徴

# 

# \- インターネットの権限なし。AIの機能も、端末の中だけで動きます

# \- アカウント登録なし

# \- 伸縮・振動を別々に、または全体をまとめて操作

# 

# \## Android版

# 

# \### 手動操作（Releases の v3.1）

# 

# \- CH1＝伸縮、CH2＝振動。それぞれパターン1〜9と停止

# \- 伸縮と振動を、別々のパターンで同時に動かせます

# \- APKは Releases からダウンロードできます

# 

# \### AI操作（main ブランチ・試験的）

# 

# \- 言葉を入れると、端末の中のAI（Qwen 3.5 2B、Q4\_0のGGUF）が

# &#x20; 「all / stroke / vibe　パターン　秒数」の形の命令に変換し、順番に送ります

# \- パターンは1〜3（弱・中・強）だけを使います。最後の命令の後は全停止します

# \- 手動のボタンや全停止のボタンを押すと、すぐに中断します

# \- モデルのファイルは同梱していません。各自で入手して、アプリの中で選びます

# \- 確認した端末：Pixel 6a

# 

# \### AI版の組み立て方

# 

# 1\. llama.cpp を取得し、確認した版（86ea01d）に合わせて、`patches` の変更を当てる

# 

# ```

# git clone https://github.com/ggml-org/llama.cpp C:\\dev\\llama.cpp

# cd C:\\dev\\llama.cpp

# git checkout -b mcontrol 86ea01d

# git am （このリポジトリの場所）\\patches\\\*.patch

# ```

# 

# 2\. 置き場所が違う場合は、`settings.gradle.kts` の `:llama` の場所を書き換える

# 3\. Android Studio でこのリポジトリを開いて組み立てる

# 

# \## 送信の仕組み（確認済みの事実）

# 

# \- Android：製造者データ（ID 0x00FF）に、先頭8バイト `6DB643CE97FE427C` と命令3バイトを入れる

# \- iPhone：Service UUID の並びで送る（詳しくは ios フォルダ のREADME）

# 

# \## 注意

# 

# \- この機器には認証がありません。近くにある同じ型の機器にも届く可能性があります。使わないときは電源を切ってください

# \- 確認したのは、手元の機器1台だけです
