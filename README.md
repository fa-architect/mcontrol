# MControl（自作・オフライン版） v2.0

外部ライブラリなし・INTERNET権限なし。機器とは接続せず、BLEの電波（アドバタイズ）で命令を送る方式。

## 使い方
- パターン1〜9を押すと約1秒間送信。同じボタンをもう一度押すと停止。
- 初回に「付近のデバイス」の権限を求められたら許可。

## 根拠（事実）
公式アプリ動作時のHCIログ（Pixel 6a、2026-09-24 11:40〜）から取得:
- 製造者ID 0x00FF、サービスUUID 0xAE8F、11バイトのデータ
- 先頭8バイト共通 6db643ce97fe427c、末尾3バイトが命令ごとに変化
- 送信間隔100ms、約1秒で停止（公式アプリと同じ）

## 未確認
- パターン番号の対応は、操作手順（1→9→停止）の順番から推定
- 先頭8バイトが機器（デバイスコード）ごとに違うかどうか。別の機器では動かない可能性あり
- 伸縮運動がパターンに含まれるかどうか

## 注意
- 接続しない方式のため、近くにある同じ機器（同じ値を受け付けるもの）にも届く可能性がある
